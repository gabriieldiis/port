# Portfólio Pessoal — Gabriel

## 🎯 Objetivo
Criar um portfólio profissional, minimalista e direto, com foco em apresentar projetos de forma visual e clara, destacando habilidades em Front-end, Design e Testing (QA).

O portfólio será hospedado inicialmente no GitHub Pages.

---

## 🧠 Posicionamento

Gabriel é um profissional híbrido que une:
- Desenvolvimento Front-end
- Design de interfaces
- Testes e validação (QA)

Proposta de valor:
> Criar interfaces bonitas, funcionais e validadas.

---

## 🎨 Direção Visual

Referência principal:
- Estilo minimalista
- Layout limpo
- Muito espaço em branco
- Tipografia forte
- Foco total nos projetos

Características:
- Pouco texto
- Imagens grandes
- Navegação simples
- Sem excesso de animações

---

## 🧱 Estrutura do Site

### 1. Hero (primeira dobra)
- Nome: Gabriel
- Título: Front-end Developer & Designer
- Frase curta de posicionamento
- Botão CTA (ex: "Ver projetos")

---

### 2. Projetos (seção principal)

Grid visual com projetos.

Cada projeto deve conter:
- Imagem destacada
- Nome do projeto
- Categoria (opcional)

Ao clicar:
- Página ou modal com:
  - Contexto do projeto
  - Problema
  - Solução
  - Tecnologias utilizadas
  - Resultado final

Importante:
Projetos não devem ser separados por "design", "dev" ou "vídeo".
Cada projeto deve representar um case completo.

---

3 blocos principais:

- Animações excessivas
- Texto genérico
